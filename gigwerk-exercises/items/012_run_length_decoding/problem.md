## Source statement (solution-free)

## Explicit semantic obligations

For every **valid run-length code generated by the referenced encoding process**:

1. `decode [] = []`.
2. `One x` contributes exactly one occurrence of `x`.
3. `Many (n, x)` contributes exactly `n` consecutive occurrences of `x`.
4. Segment contributions are concatenated in the original left-to-right input order. The operation must not sort, deduplicate, merge separated equal runs, or otherwise alter ordering or multiplicity.
5. The function is polymorphic: it must not depend on comparison, hashing, serialization, or any string-specific behavior of elements.

### Boundary deliberately not invented

The supplied file refers to code lists “generated as specified in the previous problem,” but it does **not** restate the admissible-count invariant or behavior for manually constructed `Many (0, x)` / `Many (n, x)` with `n < 0`. This item therefore imposes no invented error, option, or output behavior for such out-of-domain values. The generated tests exercise the empty code, `One`, and positive `Many` counts only.

## Nonfunctional scope

The source statement contains no randomness, effects, mutation, streams/coinduction, strings-only rule, float rule, or failure/option result. `decode` is consequently required to be a pure finite-list transformation on its stated valid domain. The integer carried by `Many` is a run count, not a seed or a request for another interface.

## Formal-contract limitation in the pinned runtime

The local pinned Synquid accepts ordered List-valued measures and equality over their results, so order and duplication can be represented. It does not provide a sound usable logical operation for the exact List-valued relation “repeat this element `n` times” when `n` is the integer field of `Many`: measures structurally recurse on a declared datatype, and an ordinary typed helper cannot be called as a logical measure. Consequently no `contract.sq` is emitted rather than weakening this requirement to length or element-set equality.
